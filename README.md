# DateTimePicker

Date and time picker components for iOS.

## Installation

### Swift Package Manager

In Xcode:

1. Open your project.
2. Go to `File` -> `Add Package Dependencies...`
3. Enter repository URL:
   `https://github.com/lsn21/DateTimePicker.git`
4. Select the version you need and add the `DateTimePicker` product.

### CocoaPods

Add to your `Podfile`:

```ruby
pod 'DateTimePicker'
```
